# 🌡️ Conversor de Temperatura

## Descripción
Este proyecto consiste en un programa desarrollado con JavaScript que permite convertir temperaturas de grados Celsius a grados Fahrenheit y Kelvin.

El ejercicio tiene como objetivo practicar la lógica de programación, la validación de datos y la manipulación del DOM (Document Object Model).

## 🚀 Funcionalidades

- Ingreso de temperatura en grados Celsius mediante un campo de entrada.
- Conversión automática a grados Fahrenheit.
- Conversión automática a grados Kelvin.
- Validación de datos numéricos.
- Mensajes de error cuando los datos ingresados no son válidos.
- Visualización de resultados directamente en la página mediante el DOM.

## 🛠️ Tecnologías utilizadas

- HTML5
- JavaScript
- DOM (Document Object Model)

## 🧮 Fórmulas utilizadas

**Celsius a Fahrenheit:**

°F = (°C × 9/5) + 32

**Celsius a Kelvin:**

K = °C + 273.15
